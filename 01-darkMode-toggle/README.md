# Dark Mode Toggle 🌙

A simple Dark Mode Toggle mini project built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

Add your Vercel link here:

```txt
https://dom-projects-mauve.vercel.app/01-darkMode-toggle/
```

---

## 📌 Features

- Toggle between Light Mode and Dark Mode
- Smooth transition effects
- Responsive centered layout
- Interactive hover animation on button
- Dynamic button text update using JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)

---

## 📂 Project Structure

```txt
01-darkMode-toggle/

├── index.html

```

- Class Toggling with `classList.toggle()`
- Dynamic text updates with JavaScript
- Basic UI styling and transitions
- Deploying projects using Vercel
- Pushing projects to GitHub
